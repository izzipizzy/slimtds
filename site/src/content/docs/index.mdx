Source on GitHub: [github.com/izzipizzy/slimtds](https://github.com/izzipizzy/slimtds)

slimTDS is a self-hosted traffic distribution system built on Slim 4, FrankenPHP (worker mode), and PostgreSQL 18.
It routes organic traffic through campaigns, offers, and flows using geo/device/bot filters, records click and pixel events in partitioned tables, and delivers outgoing postbacks with exponential-backoff retry.
Designed as a single-tenant internal tool, it ships as a single Docker image with a built-in admin panel.
