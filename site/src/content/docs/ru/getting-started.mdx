## Требования

- **Docker и Docker Compose** — любой движок Docker (Docker Desktop, Rancher Desktop или обычная установка Docker)
- Больше ничего на хосте не требуется: PHP, PostgreSQL и все runtime-зависимости работают внутри контейнеров Docker

## Установка и запуск

<Steps>

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/izzipizzy/slimtds.git slimtds
   cd slimtds
   ```

2. **Скопируйте шаблон окружения и сгенерируйте секреты**

   ```bash
   make env
   ```

   Эта команда копирует `.env.example` → `.env` и генерирует случайные значения для `APP_SECRET` и `ADMIN_PASSWORD`. Пароль администратора выводится в терминал — запишите его.

3. **Запустите стек**

   ```bash
   make up
   ```

   Поднимает три контейнера: `db` (PostgreSQL 18), `app` (FrankenPHP в worker-режиме) и `cron` (планировщик задач supercronic).

4. **Примените миграции базы данных**

   ```bash
   make migrate
   ```

   Запускает Phinx против dev-базы, создавая все схемы, таблицы, партиции и индексы.

5. **Загрузите тестовые данные (seed)**

   ```bash
   make seed
   ```

   Идемпотентная команда — можно запускать многократно (пропускает, если кампании уже есть). Создаёт:

   - **1 администратора** — логин `admin`, пароль из вывода `make env`
   - **4 кампании** — `casino` (iGaming / Casino), `dating` (Dating Smartlink), `nutra` (Nutra COD), `site` (slimTDS Site — только пиксель, без потоков)
   - **5 глобальных офферов** — CIS Casino ($40), EU Casino ($60), Dating A ($4), Dating B ($6), Nutra COD ($12)
   - **7 потоков** в трёх трафиковых кампаниях, демонстрирующих гео-маршрутизацию, фильтрацию ботов, A/B-сплиты и переиспользование офферов между кампаниями

</Steps>

## Вход в систему

Откройте `/admin/login` на хосте, где вы опубликовали slimTDS. Используйте логин `admin` и пароль из вывода `make env` (он также сохранён в `.env` как `ADMIN_PASSWORD`). Подробнее про TLS и варианты публикации см. в разделе [Развёртывание](../deployment/).

## Что вы получаете

После загрузки данных у вас есть полностью рабочий локальный экземпляр: четыре кампании с живыми slug-URL (`/casino`, `/dating`, `/nutra`, `/site`), пять глобальных офферов, подключённых через потоки, и заполненные данными все экраны админки. Дашборд статистики показывает временные ряды по кликам и конверсиям, KPI-карточки и разбивки по странам и устройствам. Чтобы понять, как связаны маршрутизация трафика, кампании, офферы и потоки, прочитайте [Как обрабатывается клик](core-concepts/).
