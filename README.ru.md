# slimTDS

[English](README.md) · **Русский**

slimTDS — self-hosted система распределения трафика (TDS) для арбитражников и
performance-маркетологов, которым нужен полный контроль над своими кликами
вместо прогона через SaaS-вендора. Это современный переписанный zTDS на
**PHP 8.4**, **Slim 4** поверх **FrankenPHP в worker-режиме** (без
пере-инициализации на каждый запрос — приложение резидентно в памяти) и
**PostgreSQL 18** с помесячно-партиционированными, BRIN-индексированными
таблицами кликов/событий. Админка — Tailwind 4 + Alpine.js + ECharts;
фингерпринтинг посетителей — FingerprintJS Community Edition.

Флоу маршрутизируют посетителей по стране, устройству, ОС, браузеру, языку и
другим сигналам на взвешенные офферы через любую из 15 схем ответа
(HTTP-редиректы 301–308, meta refresh, iframe, curl-прокси, JSON, формульные
и др.). Фильтрация ботов, GeoIP, входящие/исходящие постбэки, запись сессий
(rrweb) и дашборд статистики — всё встроено.

**Живое демо:** [slimtds.com](https://slimtds.com) — открытая песочница. Логин на
[/admin/login](https://slimtds.com/admin/login): **`admin` / `demo`**. Всё
**сбрасывается к базовому состоянию каждые 4 часа**, так что меняй что угодно.
**Документация:** [slimtds.com/docs/ru](https://slimtds.com/docs/ru/)

## Быстрый старт

Нужен Docker (≥ 24) с плагином Compose v2, либо OrbStack на macOS.

```bash
git clone https://github.com/izzipizzy/slimtds.git
cd slimtds

make env      # скопировать .env.example → .env, сгенерировать APP_SECRET + ADMIN_PASSWORD
make up       # поднять db + app + cron
make migrate  # прогнать миграции Phinx
make seed     # идемпотентные dev-фикстуры: 1 админ + 3 кампании + 5 офферов + 10 флоу
```

Затем открой админ-логин, показанный в конце `make up`, и войди под
`admin` / паролем, который вывел `make env`.

## Что внутри

- **Горячий путь движка (`/<slug>`)** — резолв посетителя (cookie → серверный
  фингерпринт → FingerprintJS → новый UUIDv7), GeoIP, детект ботов, матчинг
  JSONB-фильтров (AND-группы внутри OR), взвешенный выбор оффера, раскрытие
  макросов и 15 типов схем ответа. Клики логируются асинхронно в
  RANGE-партиционированную, BRIN-индексированную таблицу.
- **Пиксель** — `/p.js` (FingerprintJS CE) + `/p/event`, с разрешительным CORS,
  чтобы любой внешний лендинг мог слать события. Плюс запись сессий без правок
  на сайте через встроенный rrweb-клиент — лендингам, которым нужны только
  просмотры, её можно выключить через `?rec=0`. Запоминает внешний реферер входа,
  чтобы поисковый трафик оставался атрибутируемым за серверными редиректами.
- **Постбэки** — входящий `/postback` (GET/POST, идемпотентный UPSERT по
  `subid+status`, per-offer и campaign-level catch-all токены) плюс развязанный
  воркер исходящих доставок с экспоненциальным ретраем.
- **Админка** — кампании, глобальные офферы (переиспользуемые между кампаниями
  через таргеты флоу), Alpine.js конструктор флоу/фильтров, логи
  кликов/конверсий, дашборд статистики на ECharts, реплей сессий, i18n (RU/EN)
  и тёмная тема.
- **Эксплуатация** — крон-ротация партиций, обновление списков ботов, проверка
  свежести GeoIP, бэкапы БД, Telegram-дайджесты/алерты и refresh
  материализованных представлений.

## Режимы развёртывания

| Режим | Compose | TLS | Источник Real-IP |
|---|---|---|---|
| `dev` | `docker compose up` | OrbStack авто-HTTPS через label контейнера | локально |
| `cf_flex` / `cf_full` | `docker-compose.prod.cf.yml` | Cloudflare (Flex или Full с Origin Cert) | заголовок `CF-Connecting-IP` |
| `direct` | `docker-compose.prod.direct.yml` | Caddy авто-TLS через Let's Encrypt | только доверенные прокси |

Полная настройка (включая MaxMind GeoLite2 и Telegram) — в
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Бенчмарк

Подними стек и укажи слаг любой активной кампании:

```bash
make benchmark SLUG=<slug>
```

Запускает нагрузочный тестер [fortio](https://github.com/fortio/fortio) по
внутреннему HTTP-порту движка, так что результат отражает сам движок, а не
TLS/сеть. Используй dev/staging-инстанс или одноразовый слаг — каждый запрос
пишет клик. Требования к железу и референсные цифры — в
[slimtds.com/docs/ru](https://slimtds.com/docs/ru/).
